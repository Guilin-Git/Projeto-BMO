# Caverna dos Espelhos

## Descrição
A Caverna dos Espelhos é um local que aparece em " Te Peguei! ". Se alguém atravessar os espelhos vai para uma sala onde aparecem muitas sombras.

## Aparência
É uma caverna comum com espelhos, que traz ilusões do que você deseja, e os reflexos se tornam uma coisa maligna quando se sai dos espelhos.
